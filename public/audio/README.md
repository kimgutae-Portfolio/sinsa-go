# 境内の音 / 신사 사운드

`shrine-garden.mp3`는 이 프로젝트에서 코드로 합성한 오리지널 사운드스케이프입니다. 외부 음원·실제 종교 의식 녹음·독경·음성은 사용하지 않습니다. 실제 신사 현장 녹음이나 전통 악기 연주 녹음으로 소개하지 마세요.

- 48초 스테레오 루프, 32kHz / MP3 112kbps, 약 660KB.
- 저역 필터 노이즈의 숲 바람, 멀리서 들리는 작은 새, 숨결을 섞은 오음계 피리 음색, 작은 금속 방울의 잔향.
- 주기적인 바람과 루프 경계를 넘어 감싸는 이벤트로 연결 부분의 급격한 변화를 줄입니다. MP3 인코더의 gapless 정보를 Web Audio 디코더가 반영합니다.
- 최초 「音を聴く」 클릭 시에만 요청·디코딩합니다. 디코딩 메모리는 약 12MB(브라우저 샘플레이트에 따라 증가)이며, 프레임마다 JS로 소리를 합성하지 않습니다.

재생성: `node scripts/generate-audio.mjs` (Node + PATH에 `ffmpeg` 필요). 일반 실행·빌드에는 ffmpeg가 필요 없습니다.

실제 녹음으로 교체하려면 사용 권한을 확보한 루프 음원을 이 파일명으로 넣거나 `src/audio/ShrineAudio.ts`의 URL을 변경하세요. 큰 음악보다 작은 음량의 공간음과 반복 경계가 자연스러운 소스를 권장합니다. 교체 시 이 문서에 출처·사용 조건을 기록하세요.
